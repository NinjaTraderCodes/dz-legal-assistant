## Three-fold correction

Use exactly the manifest's three grouped fitting folds; no audit labels or original validation labels. For each held-out fold, fit on the other two. Supervise every asked dense event, not just targets. For a raw score vector s, predict argmax(s + b), ties in numeric label order. Uncalibrated means b=0.

Only three independent global offset parameters: sum(b)=0, each offset between -3 and +3 natural-log units. No temperature, thresholds, per-question/claim/phrase parameters or prompt search. Fit class-balanced cross-entropy plus lambda * sum(b*b)/2, with the balanced weights computed only from the training folds (each of the four classes has total weight one quarter). Lambda grid is exactly **0.01, 0.1, 1.0**, plus the uncalibrated arm. Start at zero, full-batch deterministic gradient descent, step 1/(0.5+lambda), at most 1,000 steps, stopping if the largest offset change is below 1e-10. Project onto the zero-sum [-3,3] box by a scalar bisection shift. No stochastic training or extra grid after results. Record fitted offsets, training/held-out IDs and convergence for each fold/model/order/lambda.

Calibration survives only if it strictly reduces pooled critical failed cases AND pooled non-affirmed errors versus the matching uncalibrated order arm, without more pooled false affirmations; the same strict reductions and non-increased false affirmations must hold in at least two of three held-out folds. Keep known-value omissions and decisive omissions from increasing, and report request/evidence completeness. Otherwise omit calibration; do not select a friendlier definition afterward.
