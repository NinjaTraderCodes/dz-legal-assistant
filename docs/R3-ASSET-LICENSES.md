# R3 assets

IBM Plex Sans Arabic is bundled in `src/DzLegal.App/Assets/UiFonts` and `src/DzLegal.Web/wwwroot/ui-fonts`, with the complete SIL OFL in each directory. Noto Naskh Arabic and its OFL remain in `assets/fonts`. Existing web Inter files retain their OFL notice. The Folio folded-paper mark is project artwork drawn as paths.

The existing desktop FluentIcons packages declare MIT in their NuGet metadata. The web icon paths are from [Microsoft Fluent System Icons](https://github.com/microsoft/fluentui-system-icons/blob/main/LICENSE). The wrapper's notice is from [davidxuang/FluentIcons](https://github.com/davidxuang/FluentIcons/blob/master/LICENSE). Their complete notices follow; no runtime requests are made to these sites.

The six added web outline paths (Building, Person, Briefcase, Text Description, Library and Document, 20px regular) were retrieved on 2026-10-23 from Microsoft's `assets/<Name>/SVG/ic_fluent_<name>_20_regular.svg` files and included as SVG path data in IconPaths.cs. The native outline uses the corresponding symbols in the existing FluentIcons 2.1.343 package.
